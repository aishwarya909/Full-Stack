# My Project Title

This is a full-stack project built with Express, TypeScript, and Nodemon.

## Features

- TypeScript support
- Express server
- Nodemon for development
- CORS and dotenv support

## Scripts

- `npm run server` - Starts the dev server with nodemon
- `npm run build` - Compiles TypeScript to JavaScript
- `npm run watch` - Watches and compiles TypeScript on file change

## Getting Started

1. Clone the repo
2. Run `npm install`
3. Run `npm run build`
4. Run `npm run server`
